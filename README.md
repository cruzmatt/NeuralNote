This is group 3M's submission for the KeanUHackThis 2026 Hackathon!

Inspired by the nonlinear learning processes of both artificial intelligence and human biology, NeuralNote is an application that allows users to organize information across multiple devices in whatever way is most natural to them. Through the utilization of linking technology, users are able to take notes and physically draw connections between different ideas, deepening memory and understanding. Studies have shown that mind maps and graphic organizers have statistically significant increases on memory retention and learning outcomes, meaning NeuralNote actually works! All of this is tied together neatly by the in-app AI agent Neuri, who helps answer questions, create study tools and more. https://pmc.ncbi.nlm.nih.gov/articles/PMC11756665/
